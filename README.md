# КТ №5. Тестирование функционала сайта YouTube и составление тестовой документации

Проект подготовлен для практической работы по предмету **«Модульное тестирование веб-приложений»**.

В работе выбран сайт **YouTube**. Для него составлены тестовая документация и автотесты на Python + Selenium + Pytest.

## Что входит в архив

```text
youtube_selenium_tests/
├── .github/workflows/selenium-tests.yml  # пример CI-запуска тестов в GitHub Actions
├── defects/jira_cards.md                 # примеры карточек дефектов для Jira / YouGile
├── docs/
│   ├── checklist.md                      # чек-лист проверок
│   ├── test_cases.md                     # тест-кейсы
│   ├── test_plan.md                      # тест-план
│   ├── test_data.md                      # тестовые данные
│   ├── traceability_matrix.md            # матрица соответствия
│   └── test_report.md                    # отчет о тестировании
├── pages/                                # Page Object Model
```

## Выбранный сайт

**Сайт:** https://www.youtube.com/  
**Тип сайта:** видеохостинг / медиаплатформа  
**Причина выбора:** сайт имеет явно выраженный функционал: поиск, навигацию, просмотр видео, фильтры результатов, взаимодействие с элементами интерфейса.

## Проверяемый функционал

- открытие главной страницы;
- наличие логотипа и строки поиска;
- поиск по валидному запросу;
- поиск с пустым запросом;
- поиск со спецсимволами;
- отображение фильтров на странице результатов;
- открытие видео из результатов поиска;
- переход на главную страницу по клику на логотип;
- повторный поиск с другим запросом.

## Установка

1. Установить Python 3.10 или выше.
2. Установить Google Chrome.
3. Перейти в папку проекта:

```bash
cd youtube_selenium_tests
```

4. Создать виртуальное окружение:

```bash
python -m venv .venv
```

5. Активировать виртуальное окружение.

Windows:

```bash
.venv\Scripts\activate
```

Linux / macOS:

```bash
source .venv/bin/activate
```

6. Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

Запуск всех тестов в обычном режиме:

```bash
pytest
```

Запуск в headless-режиме:

```bash
pytest --headless
```

Запуск только smoke-тестов:

```bash
pytest -m smoke
```

Запуск только тестов поиска:

```bash
pytest -m search
```

Выбор браузера:

```bash
pytest --browser=chrome
pytest --browser=firefox
pytest --browser=edge
```

После запуска формируется HTML-отчет:

```text
reports/report.html
```

При падении теста скриншоты сохраняются в папку:

```text
screenshots/
```

## Важное примечание

YouTube — внешний сайт, интерфейс которого может изменяться. Поэтому в реальном проекте такие тесты нужно регулярно поддерживать: обновлять локаторы, учитывать региональные окна cookie-согласия и возможные изменения языка интерфейса.

## Использованные техники тестирования

- функциональное тестирование;
- тестирование методом черного ящика;
- позитивные и негативные сценарии;
- анализ граничных условий на примере пустого поискового запроса;
- регрессионное тестирование;
- UI-тестирование.
