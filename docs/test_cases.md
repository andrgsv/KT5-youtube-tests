# Тест-кейсы

## TC-001. Открытие главной страницы YouTube

| Поле | Значение |
|---|---|
| ID | TC-001 |
| Название | Открытие главной страницы YouTube |
| Приоритет | High |
| Тип | Smoke, UI |
| Предусловия | Браузер установлен, интернет доступен |

**Шаги:**

1. Открыть сайт `https://www.youtube.com/`.
2. Дождаться загрузки страницы.
3. Проверить наличие логотипа YouTube.
4. Проверить наличие поля поиска.

**Ожидаемый результат:** главная страница открыта, логотип и поле поиска отображаются.

**Фактический результат:** страница открыта, основные элементы отображаются.

**Статус:** Passed.

## TC-002. Поиск по валидному запросу

| Поле | Значение |
|---|---|
| ID | TC-002 |
| Название | Поиск видео по валидному запросу |
| Приоритет | High |
| Тип | Smoke, Functional |
| Предусловия | Пользователь находится на главной странице YouTube |

**Тестовые данные:** `selenium python`

**Шаги:**

1. Ввести в строку поиска запрос `selenium python`.
2. Нажать Enter.
3. Дождаться загрузки страницы результатов.
4. Проверить URL.
5. Проверить наличие результатов поиска.

**Ожидаемый результат:** открыта страница результатов, в URL присутствует параметр `search_query=selenium+python`, отображаются видео.

**Фактический результат:** страница результатов открывается, видео отображаются.

**Статус:** Passed.

| Предусловия | Пользователь находится на странице результатов поиска |
