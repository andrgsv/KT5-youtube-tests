# Тест-план

## 1. Название работы

КТ №5. Тестирование функционала сайта и составление тестовой документации.

## 2. Объект тестирования

Веб-сайт **YouTube**: https://www.youtube.com/

## 3. Цель тестирования

Проверить основную функциональность сайта YouTube, связанную с открытием главной страницы, поиском видео, отображением результатов, фильтрами и переходом к просмотру видео.

## 4. Основание выбора сайта

YouTube выбран для тестирования, потому что сайт имеет явно выраженную функциональность:

- строка поиска;
- результаты поиска;
- карточки видео;
- страница просмотра видео;
- навигация по логотипу;
- фильтрация результатов.

Эти функции подходят для составления тестовых сценариев, тест-кейсов, чек-листа и автоматизированных Selenium-тестов.

## 5. Объем тестирования

### Входит в тестирование

- загрузка главной страницы;
- проверка отображения основных элементов;
- поиск по валидному запросу;
- проверка пустого запроса;
- проверка запроса со спецсимволами;
- проверка отображения результатов поиска;
- проверка кнопки фильтров;
- открытие первого видео из выдачи;
- возврат на главную страницу через логотип;
- повторный поиск.

### Не входит в тестирование

- авторизация пользователя;
- загрузка видео;
- комментарии;
- подписки;
- платежные функции;
- YouTube Studio;
- проверка персональных рекомендаций.

## 6. Подход к тестированию

Используется функциональное тестирование методом черного ящика. Для автоматизации используется Python, Selenium WebDriver и Pytest. Тесты оформлены по паттерну Page Object Model.

## 7. Тестовая среда

| Параметр | Значение |
|---|---|
| ОС | Windows 10 / Windows 11 / Linux |
| Браузер | Google Chrome, Firefox, Edge |
| Язык | Python 3.10+ |
| Инструменты | Selenium, Pytest, pytest-html |
| Сайт | https://www.youtube.com/ |

## 8. Критерии начала тестирования

- сайт YouTube доступен;
- интернет-соединение стабильно;
- установлен Python;
- установлены зависимости из `requirements.txt`;
- установлен браузер для запуска тестов;
- подготовлены тест-кейсы.

## 9. Критерии завершения тестирования

- выполнены все запланированные тест-кейсы;
- результаты тестирования внесены в отчет;
- найденные дефекты описаны в формате баг-репортов;
- сформированы рекомендации по исправлению;
- подготовлен итоговый отчет.

## 10. Риски

| Риск | Описание | Способ снижения |
|---|---|---|
| Изменение интерфейса YouTube | Локаторы Selenium могут перестать работать | Использовать устойчивые CSS/XPath-локаторы |
| Cookie-баннер | Может перекрывать элементы страницы | Добавлена обработка окна согласия |
| Разные языки интерфейса | Названия кнопок могут отличаться | Использовать универсальные локаторы |
| Медленная загрузка | Тесты могут падать из-за таймаутов | Использовать явные ожидания |
| Внешний сайт | Нельзя контролировать тестовые данные | Проверять только общую доступную функциональность |
