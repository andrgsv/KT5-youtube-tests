## 6. Рекомендации

1. Регулярно обновлять автотесты, так как интерфейс YouTube может изменяться.
2. Для стабильности использовать явные ожидания Selenium.
3. Для реального проекта добавить тестирование в разных браузерах.
4. Для CI/CD запускать тесты в headless-режиме.
5. Хранить скриншоты падений и HTML-отчеты после каждого запуска.
