# Примеры карточек дефектов для Jira / YouGile / Kaiten

> Примечание: YouTube является внешним сайтом. Ниже приведены учебные примеры оформления дефектов, которые можно использовать для демонстрации работы с баг-трекером. Если при реальном запуске тестов дефекты не воспроизводятся, их можно оставить как примеры потенциальных дефектов.

---

## BUG-001. Поиск с пустым запросом открывает пустую страницу результатов

| Поле | Значение |
|---|---|
| Тип задачи | Bug |
| Приоритет | Minor |
| Серьезность | Low |
| Компонент | Search |
| Статус | Open |
| Метки | UI, Search, Negative |

**Описание:**  
При нажатии Enter в пустой строке поиска пользователь может попасть на страницу результатов без запроса.

**Шаги воспроизведения:**

1. Открыть сайт YouTube.
2. Оставить строку поиска пустой.
3. Нажать Enter.

**Ожидаемый результат:**  
Пользователь остается на главной странице или получает подсказку о необходимости ввести запрос.

**Фактический результат:**  
Открывается пустая страница результатов.

**Рекомендация:**  
Добавить проверку пустого значения перед отправкой формы поиска.

## BUG-002. Кнопка фильтров не отображается после поиска

| Поле | Значение |
|---|---|
| Тип задачи | Bug |
| Приоритет | Major |
| Серьезность | Medium |
| Компонент | Search Results |
| Статус | Open |
| Метки | UI, Filter, Regression |

**Описание:**  
После выполнения поиска на странице результатов отсутствует кнопка фильтров.

**Шаги воспроизведения:**

1. Открыть YouTube.
2. Выполнить поиск по запросу `qa automation`.
3. Дождаться загрузки страницы результатов.
4. Проверить наличие кнопки фильтров.

**Ожидаемый результат:**  
Кнопка фильтров отображается и доступна пользователю.

**Фактический результат:**  
Кнопка фильтров отсутствует.

**Рекомендация:**  
Проверить загрузку блока фильтров и условия его отображения.

## BUG-003. Первое видео из результатов не открывается

| Поле | Значение |
|---|---|
| Тип задачи | Bug |
| Приоритет | Critical |
| Серьезность | High |
| Компонент | Video Page |
| Статус | Open |
| Метки | Video, Navigation, Critical |

**Описание:**  
При клике на первое видео из результатов поиска страница просмотра не открывается.

**Шаги воспроизведения:**

1. Открыть YouTube.
2. Выполнить поиск по запросу `python selenium tutorial`.
3. Нажать на первое видео в списке результатов.

**Ожидаемый результат:**  
Открывается страница просмотра видео, отображается видеоплеер.

**Фактический результат:**  
Пользователь остается на странице результатов или видит ошибку загрузки.

**Рекомендация:**  
Проверить работу ссылок карточек видео и обработку перехода на страницу `/watch`.

## BUG-004. Повторный поиск не обновляет результаты

| Поле | Значение |
|---|---|
| Тип задачи | Bug |
| Приоритет | Major |
| Серьезность | Medium |
| Компонент | Search |
| Статус | Open |
| Метки | Search, Regression |

**Описание:**  
После повторного ввода нового поискового запроса результаты поиска не обновляются.

**Шаги воспроизведения:**

1. Выполнить поиск по запросу `manual testing`.
2. Дождаться страницы результатов.
3. Ввести новый запрос `automation testing`.
4. Нажать Enter.

**Ожидаемый результат:**  
Страница результатов обновляется под новый запрос.

**Фактический результат:**  
Остаются результаты старого запроса.

**Рекомендация:**  
Проверить обработчик формы поиска и обновление URL-параметра `search_query`.
